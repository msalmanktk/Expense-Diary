# Expense Diary 💰

**Expense Diary** is a responsive personal expense tracking web application designed to help students organize daily spending, monitor monthly expenses, manage different spaces, and track money lent to friends.

## ✨ Features

- **Expense Management:** Add, edit, and delete expense records.
- **Multiple Spaces:** Organize expenses for Hostel, Home, and other spaces.
- **Monthly Summary:** Review monthly spending and expense breakdowns.
- **Loan Tracking:** Record money lent to friends and track repayments.
- **Search & Filters:** Find and filter expense records easily.
- **Dark Mode:** Switch between light and dark themes.
- **CSV Export:** Export expense records.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Local Storage:** Keep records saved in your browser.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using your browser or the Live Server extension.
4. Start recording and managing your expenses.

## 💾 Data Storage

Expense Diary uses your browser's Local Storage to save records.

**Note:** Data does not automatically sync across devices or browsers. Clearing browser data may remove saved records, so export important information regularly.

## 🎯 Purpose

Expense Diary aims to make personal money management simple and organized, especially for students managing hostel expenses, home spending, and loans.
